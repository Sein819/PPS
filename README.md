# 조달조달 타운

> **조달로 연결하고, 행복으로 성장하는 도시.**

**조달조달 타운**은 조달청의 공공조달 업무를 소재로 한 **3D 싱글플레이 캐주얼·자동화 타이쿤**입니다. 플레이어는 조달 업무를 맡은 **나르미**가 되어 가상의 도시 **솔빛시**에서 입찰, 계약, 품질검사, 원자재 비축·공급, 물품 배송을 진행합니다.

처음에는 나르미가 직접 뛰어다니며 일하지만, 납품으로 모은 **행복 하트**와 **조달 예산**을 활용해 업무를 하나씩 자동화할 수 있습니다. 공공시설이 활성화될수록 시민의 일상과 도시 풍경도 함께 바뀝니다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 3D 캐주얼 경영·자동화 타이쿤 |
| 플랫폼 | Windows PC |
| 엔진 | Unity 6 (`6000.3.8f1`) |
| 플레이 | 싱글플레이, 약 30분을 목표로 설계 |
| 배경 | 가상의 도시 `솔빛시` |

## 주요 게임 기능

### 1. 나라장터 입찰과 계약

공공기관의 조달요청을 확인하고 나라장터에 입찰공고를 게시합니다. **30초간 입찰**이 진행되면 참여기업의 **가격·품질·납기·참가자격**을 비교하여 계약합니다. 요청은 게임 진행 중 새롭게 도착하며, 이전에 완료한 종류의 계약도 다시 발생할 수 있습니다.

### 2. 품질검사 미니게임과 직접 배송

기업이 물품을 생산하면 해당 제품에 맞는 **흔들림 타이밍, 전력 조절, 버튼 순서 기억** 미니게임으로 검사를 진행합니다. 검사 결과에 따라 합격 또는 보완 절차를 거칩니다. 납품 가능한 물품은 트럭으로 직접 운송하며, 도로의 안내 화살표를 따라 목적지의 **노란 점선 하역 구역**에 도착하면 배송이 완료됩니다.

### 3. 원자재 비축과 공급

조달청의 비축 업무를 모티브로 **알루미늄과 구리**를 구매·보관합니다. 기업은 평소 자체 원자재로 생산하지만, 공급 부족이 발생한 계약에는 비축기지에서 원자재를 공급해 생산을 재개할 수 있습니다.

### 4. 행복 하트와 도시 성장

납품이 완료되면 공공시설이 활성화되고 시민들의 활동이 늘어납니다. **행복 하트**는 업무 확장 및 직원 고용 등에 사용하며, **조달 예산**은 계약·원자재·시설 확장 등에 사용합니다. 하트를 소비해도 누적 **도시 행복도**는 감소하지 않습니다.

도시 행복도에 따라 시민 정원(100), 환승역(500), 수변 공원(1,000), 스마트 지구(2,000), 고층 업무 지구(3,000), 솔빛 전망탑(5,000)이 차례로 열립니다. **도시 행복도 7,500**을 달성하면 엔딩을 볼 수 있으며, 엔딩 후에도 계속 운영할 수 있습니다.

### 5. 업무 자동화

처음에는 모든 업무를 직접 수행하지만, 성장하면서 **달이** 등 자동화 직원을 활용할 수 있습니다.

- **입찰 보조 직원**: 일반 공고 및 기업 선정 지원
- **품질검사팀**: 제품 검사와 보완 업무 자동화
- **배송 직원**: 검사 완료 물품의 납품 자동화
- **원자재 운송팀**: 비축 원자재의 기업 운송 자동화
- **물류 운영 시스템**: 차량 운행 효율 개선과 부족 재고 구매 지원

각 자동화는 **3단계**까지 강화할 수 있습니다. 업무 슬롯은 기본 **2건에서 최대 5건**, 비축창고는 **9개에서 최대 42개**까지 확장할 수 있습니다. 게임 속도는 **1배속 / 1.5배속 / 2배속**을 지원합니다.

### 6. 도시 이벤트와 계절 변화

도시 행복도가 높아지면 특별 이벤트가 열리고 도시의 3D 연출과 게임 효과가 함께 변합니다.

| 이벤트 | 효과 | 지속 시간 |
| --- | --- | --- |
| 솔빛 불꽃축제 | 획득 행복 하트 **×1.4** | 50초 |
| 솔빛 야시장 | 업무 대기 진행 속도 **×1.15** | 30초 |
| 황금 톱니바퀴 축제 | 기업 생산 속도 **×1.3** | 30초 |

불꽃축제와 야시장은 밤에 진행됩니다. 도시에는 낮·노을·밤에 따른 조명 변화가 있고, 게임 시간으로 이틀마다 **봄·여름·가을·겨울**이 순환합니다.

## 게임 진행

| 스테이지 | 주요 내용 |
| --- | --- |
| **1. 첫 번째 조달** | 솔빛초등학교의 책상·의자 조달을 통해 입찰, 검사, 납품을 배웁니다. |
| **2. 원자재 공급 위기** | LED 가로등 조달 과정에서 비축 원자재 확보와 기업 공급을 경험합니다. |
| **3. 행복한 스마트시티** | 병원, 공원, 교통시설, 도서관 등 다양한 공공수요를 처리하고 자동화를 확장합니다. |

3스테이지에서는 창고를 확장한 이후 일정 확률로 더 많은 생산·검사가 필요한 **특별 조달요청**이 발생할 수 있습니다.

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| `WASD` / 방향키 | 나르미 또는 트럭 이동 |
| `Shift` | 나르미 질주 |
| `Space` | 트럭 제동 |
| `V` | 도시 전경 / 나르미 추적 시점 전환 |
| `마우스 클릭` | 건물 선택 및 업무 UI 조작 |
| `Esc` | 창 닫기 / 일시정지 |

업무가 발생한 건물에는 **느낌표(!)**가 표시됩니다. 건물에 가까이 다가가면 업무 화면이 열리며, 지도에서 건물을 클릭해 위치를 확인할 수 있습니다.

## 실행 방법

1. 접근 권한이 있는 계정으로 저장소를 클론하거나 다운로드합니다.
2. **Unity Hub**에서 프로젝트 폴더를 엽니다.
3. Unity **`6000.3.8f1`** 버전으로 프로젝트를 실행합니다.
4. `Assets/Dev/Scenes/NaraTycoon.unity` 씬을 엽니다.
5. Unity 에디터에서 **Play**를 눌러 시작합니다.

프로젝트는 **URP**, **Cinemachine**, **Input System** 등을 사용하며, **FEEL** 에셋이 `Assets/Import/Feel`에 있어야 합니다.

### Windows 빌드

Unity 상단 메뉴에서 **`나라장터 타이쿤 → Windows 빌드`**를 선택합니다.

빌드 결과는 다음 경로에 생성됩니다.

```text
Builds/NaraTycoon/NaraTycoon.exe
```

## 저작권 및 에셋 출처

### 조달청 공식 마스코트 '나르미'·'달이'

- **원저작물:** 조달청 공식 마스코트 「나르미」와 「달이」 (2025년 공개)
- **원자료 이용조건:** 해당 조달청 공개 자료는 **공공누리 제1유형(출처표시)**으로 표시되어 있으며, 출처를 표시하면 상업적·비상업적 이용 및 2차적 저작물 제작이 가능합니다. [공공누리 이용조건](https://www.kogl.or.kr/info/license.do)
- **게임 내 활용 및 변경 사항:** 조달청 마스코트의 2D PNG 이미지를 참고자료로 활용하여 **AI 기반 3D 모델링**을 진행하고, 게임에 맞춰 3D 캐릭터 모델·애니메이션으로 제작했습니다.
- **관련 파일:** `Assets/Dev/Models/Narmi.fbx`, `Assets/Dev/Models/Dari.fbx`, `Art/Narmi_Animations/`

원본 캐릭터에 대한 출처 표시는 3D 변환 이후에도 유지합니다. 이 프로젝트는 조달청의 공식 제작물이나 공식 후원 게임을 의미하지 않습니다. 원본 PNG가 위 공개 자료와 다른 경로에서 제공된 경우에는 **해당 원본 파일의 개별 이용조건을 별도로 확인**해야 합니다.

## 조달청 업무와 게임적 표현

본 작품은 **나라장터의 공공조달, 조달물품 품질관리, 원자재 비축·방출** 등의 업무를 게임의 소재로 활용합니다. **나르미의 직접 배송, 미니게임 검사, 예산·행복 보상, 처리 시간, 업무 자동화** 등은 재미와 이해를 위해 단순화·각색한 요소로, 실제 조달 절차나 계약 규정을 그대로 재현한 것은 아닙니다.
