# 나라장터 타이쿤

Unity 6000.3.8f1에서 `Assets/Dev/Scenes/NaraTycoon.unity`를 열고 Play를 누릅니다. Windows 실행 파일은 Unity 상단의 **나라장터 타이쿤 → Windows 빌드** 메뉴로 만들 수 있습니다. 빌드 폴더는 `Builds/NaraTycoon`입니다.

| 조작 | 키 |
| --- | --- |
| 나르미 이동 및 질주 | WASD 또는 방향키, Shift |
| 차량 좌표축 이동 | WASD 또는 방향키 |
| 제동 | Space |
| 시설 업무 확인 또는 정차 후 하역 | E |
| 나라장터 열기 | Tab |
| 도시 전경과 나르미 추적 시점 전환 | V |
| 창 닫기 또는 일시정지 | Esc |

WASD와 방향키는 나르미와 트럭 모두 같은 지도 축으로 움직입니다. 건물 입구 3.2m 안으로 들어서면 해당 시설 화면이 열리고, 4.4m 밖으로 나가면 나르미 시점으로 전환됩니다. 지도에서 건물을 클릭해 위치를 확인할 수 있습니다. 입찰은 조달청, 원자재 관리는 비축기지, 품질검사와 상차는 계약을 체결한 협력기업에서 진행합니다. 해당 업무의 자동화를 해금하면 외부에서 처리할 수 있습니다.

입찰 접수는 30초, 물품 생산은 60초입니다. 신규 조달요청은 게임 시간 36~72초 간격으로 무작위 접수됩니다. 업무 목록에 빈자리가 생기면 완료한 유형도 다시 접수될 수 있습니다. 납품 보상은 기본 하트의 ±10% 범위에서 무작위로 책정됩니다. 시설 가동과 도시 행복도는 납품이 업무 목록에서 빠진 뒤에도 유지됩니다.

나라장터의 **업무 슬롯**은 기본 2건입니다. 행복 하트 100개, 250개, 500개로 한 건씩 늘려 최대 5건을 받을 수 있습니다. 비축기지의 **창고 확장**은 조달 예산 180만원, 320만원, 520만원으로 용량을 9개에서 18개, 28개, 42개로 늘립니다. 알루미늄은 개당 28만원, 구리는 개당 40만원입니다.

자동화는 3단계까지 올릴 수 있으며 강화하면 업무 속도가 증가하고 작업 후 대기시간이 짧아집니다. 원자재 운송팀과 물류 운영 시스템을 도입하고 강화할 때는 행복 하트와 조달 예산이 모두 필요합니다. 상단 배속 버튼에서 하트 300개로 1.5배속, 하트 1,000개로 2배속을 구매할 수 있습니다. 보유 하트가 5,000개에 도달하면 **엔딩 보기**가 나타납니다. 진행 상황과 확장·배속 구매는 기기에 자동 저장됩니다.

도시 씬의 **City Map → 솔빛시** 아래에 건물, 도로, 공원, 시설별 하역 지점과 지도 라벨 위치가 배치되어 있습니다. **Solbit Post Processing** 에셋에서 URP 후처리를 조정할 수 있고, **Cinemachine · City**와 **Cinemachine · Follow**가 도시 전경과 추적 시점을 담당합니다. **Shared celebration particles**는 납품과 시설 운영 보상을 표시합니다.

프로젝트에 설치된 **URP**, **Cinemachine 3.1**, **Input System**, **FEEL**을 사용합니다. FEEL은 `Assets/Import/Feel`에 설치되어 있어야 합니다. 폰트 라이선스는 `Assets/Dev/Fonts/OFL.txt`에 있습니다.
