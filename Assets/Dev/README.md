# 나라장터 타이쿤

Unity 6000.3.8f1에서 `Assets/Dev/Scenes/NaraTycoon.unity`를 열고 Play를 누릅니다. Windows 실행 파일은 Unity 상단의 **나라장터 타이쿤 → Windows 빌드** 메뉴로 만들 수 있습니다. 빌드 폴더는 `Builds/NaraTycoon`입니다.

| 조작 | 키 |
| --- | --- |
| 나르미 이동 및 질주 | WASD 또는 방향키, Shift |
| 차량 좌표축 이동 | WASD 또는 방향키 |
| 제동 | Space |
| 시설 업무 확인 또는 하역 구역에서 정차 및 하역 | E |
| 도시 전경과 나르미 추적 시점 전환 | V |
| 창 닫기 또는 일시정지 | Esc |

WASD와 방향키는 나르미와 트럭 모두 같은 지도 축으로 움직입니다. 건물 중심에 맞춘 외곽에서 약 2m 이내로 접근하면 시점이 부드럽게 이동하고 해당 건물의 업무 화면이 열립니다. 외곽에서 3m 넘게 벗어나면 나르미 시점으로 돌아갑니다. 지도에서 건물을 클릭해 위치를 확인할 수 있습니다. 업무가 들어온 건물에는 느낌표가 표시됩니다. 입찰은 조달청, 원자재 관리는 비축기지, 품질검사와 상차는 계약을 체결한 협력기업에서 진행합니다.

직접 운송 중에는 청록색 화살표 파티클이 현재 위치에서 목적지까지 도로를 따라 안내합니다. 다른 길로 들어서면 경로를 다시 계산합니다. 목적지 건물과 하역 진입로 위의 반짝이는 마름모를 찾고, 노란 점선 구역에 들어가 E를 눌러 하역합니다.

입찰 접수는 30초, 일반 물품 생산은 40~50초입니다. 신규 조달요청은 게임 시간 24~42초 간격으로 무작위 접수됩니다. 업무 목록에 빈자리가 생기면 완료한 유형도 다시 접수될 수 있습니다. 모든 납품과 시설 수입은 하트와 조달 예산을 각각 기준액의 ±10% 범위에서 무작위로 책정합니다. 보상은 정수 단위로 지급합니다. 시설 가동과 도시 행복도는 납품이 업무 목록에서 빠진 뒤에도 유지됩니다.

스테이지 3에서 창고를 한 번 이상 확장하면 신규 요청의 8%가 특별 조달이 될 수 있습니다. 특별 조달은 원자재 10~14개, 품질 표본 7개, 생산 120~160초가 필요합니다. 하트는 일반 조달 기준액의 3배, 조달 예산은 계약 상한과 기준 원자재비를 반영하며 특별 조달은 추가 550만원을 기준액에 포함합니다.

나라장터의 **업무 슬롯**은 기본 2건입니다. 행복 하트 100개, 250개, 500개로 한 건씩 늘려 최대 5건을 받을 수 있습니다. 비축기지의 **창고 확장**은 조달 예산 180만원, 320만원, 520만원으로 용량을 9개에서 18개, 28개, 42개로 늘립니다. 알루미늄은 개당 28만원, 구리는 개당 40만원입니다.

각 건물에 들어가 **자동화**를 열면 담당 업무를 설정할 수 있습니다. 조달청은 입찰 보조, 비축기지는 원자재 운송팀과 물류 운영 시스템, 협력기업은 품질검사팀과 배송 직원을 관리합니다. 품질검사팀과 배송 직원의 등급은 협력기업이 공유합니다.

자동화는 3단계까지 강화할 수 있습니다. 강화하면 업무 속도가 증가하고 작업 후 대기시간이 짧아집니다. 배송 직원과 원자재 운송팀은 3단계에서 차량을 2대씩 운행합니다. 원자재 운송팀과 물류 운영 시스템을 도입하고 강화할 때는 행복 하트와 조달 예산이 모두 필요합니다. 자동화 직원은 달이 모델과 대기·달리기 애니메이션을 사용합니다. 상단 배속 버튼에서 하트 160개로 1.5배속을 열거나 하트 460개로 2배속까지 한 번에 열 수 있습니다. 1.5배속을 이미 보유했다면 2배속은 하트 300개입니다. 누적 하트가 5,000개에 도달하면 **엔딩 보기**가 나타납니다. 진행 상황과 확장·배속 구매는 기기에 자동 저장됩니다.

도시 씬의 **City Map → 솔빛시** 아래에서 건물, 도로, 공원, 시설별 하역 지점과 지도 라벨 위치를 편집할 수 있습니다. 누적 하트 100, 500, 1,000, 2,000, 3,000, 5,000에서 시민 정원, 환승역, 수변 공원, 스마트 지구, 고층 업무 지구, 솔빛 전망탑이 차례로 열립니다. 하트를 사용할 때는 보유량만 줄어듭니다. 도시가 성장할수록 가동 시설에서 들어오는 하트와 예산이 늘어납니다. HUD에서 다음 목표를 확인하고 새 시설이 열릴 때 **변화 보기**를 누르면 시점을 이동할 수 있습니다. **Solbit Daylight**, **Solbit Sunset**, **Solbit Night**에서 시간대별 URP 후처리를 조정합니다. **Cinemachine · City**와 **Cinemachine · Follow**가 도시 전경과 추적 시점을 담당하고, **Shared celebration particles**는 납품과 도시 성장을 표시합니다.

프로젝트에 설치된 **URP**, **Cinemachine 3.1**, **Input System**, **FEEL**을 사용합니다. FEEL은 `Assets/Import/Feel`에 설치되어 있어야 합니다. 폰트 라이선스는 `Assets/Dev/Fonts/OFL.txt`에 있습니다.
